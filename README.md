## Browser GUI for [DEMUCS](https://github.com/facebookresearch/demucs)

### SETUP Instructions to run on a server

1. create key pair if needed
1. upload public key to github
1. config file should be chmod 600
1. private key should be chmod 400
1. clone from github
1. create env
1. pip install flask and demucs
1. start screen
1. in one `flask --app main run` or
1. `flask --app main --debug run`
